İçerikler

Beş aracı başlığına göre arayabilirsiniz.

Aramanızla eşleşen içerik bulunamadı. Başka bir başlık deneyin.

Visual Studio Code

Ücretsiz ve eklenti desteği güçlü bir kod düzenleyici. HTML, CSS ve JavaScript yazmak için ideal bir başlangıçtır.

Kategori: Kod düzenleyici · İlk görev: Bir index.html dosyası oluşturup tarayıcıda açın.

Git

Projedeki değişiklikleri sürüm sürüm kaydeden sürüm kontrol sistemi. Hata yapınca eski haline dönmeyi sağlar.

Kategori: Sürüm kontrolü · İlk görev: git init ile depo oluşturup ilk commit'inizi yapın.

GitHub

Git depolarını internette barındıran ve iş birliği yapmayı kolaylaştıran platform. Projenizi paylaşmanın ve yedeklemenin yoludur.

Kategori: Kod barındırma · İlk görev: Bir repository oluşturup projenizi push edin.

Postman

API isteklerini kod yazmadan deneyip yanıtları inceleyen araç. Web servislerinin nasıl çalıştığını görmek için kullanılır.

Kategori: API testi · İlk görev: Herkese açık bir API'ye GET isteği gönderin.

Chrome DevTools

Tarayıcının içinde gelen geliştirici araçları. Sayfanın HTML'ini, CSS'ini ve hatalarını canlı olarak incelemenizi sağlar.

Kategori: Hata ayıklama · İlk görev: F12 ile açıp bir başlığın rengini canlı olarak değiştirin.
